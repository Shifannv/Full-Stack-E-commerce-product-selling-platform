SUPER ADMIN RESPONSIBILITIES
Super Admin must eventually be able to:
ADMIN MANAGEMENT
- view Admin list
- search Admins
- filter status
- open Admin detail
- provision Admin
- review onboarding
- review KYC
- review addresses
- review requested categories
- review permitted payout/bank information
- approve
- request changes
- reject
- manage lifecycle where supported
PERMISSIONS
- inspect existing RBAC
- determine whether role-level permissions are sufficient
- do not create unsafe permission-write APIs merely for UI convenience
CATALOG
- private product oversight where required
- categories
- subcategories
- publication
- featured state
- ownership
FINANCE
- settlements
- payouts
- finance settings
- historical settlement values
- payout status/reference/proof where supported
LIFECYCLE
- deletion requests
- recovery requests
- Admin lifecycle
RECONCILIATION
- unresolved records
- resolve
- escalate
- existing UUID cursor after_id
